# Character models

`cody.glb` and `sarah.glb` are generated by `tools/characters/build.py` from
MakeHuman 1.1 assets — base mesh, targets, skin weights, skins, eyes,
eyebrows, eyelashes, hair (short04, Braid01) and clothes (male_casualsuit04,
Tank_Top_01, Tightjeans, shoes02, shoes06) — as packaged in the npm module
`makehuman-data@0.0.2`. MakeHuman's official assets are released under CC0
(public domain) by the MakeHuman team: http://www.makehuman.org/license.php

To rebuild:

    npm pack makehuman-data@0.0.2 && tar xzf makehuman-data-0.0.2.tgz
    pip install numpy pillow
    python3 tools/characters/build.py package/public/data src/assets/characters
